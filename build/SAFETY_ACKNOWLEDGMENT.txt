FlashTitan Safety Acknowledgment
================================

FlashTitan is a Windows desktop utility for preparing bootable USB drives and
SD cards from supported operating system images.

FlashTitan is intended for removable media only. Creating bootable media can
permanently erase the selected target device and destroy any data stored on it.

Please read this acknowledgment carefully. By clicking the installer agreement
checkbox and continuing, you confirm that you understand and accept the
following safety terms:

1. You are responsible for selecting the correct removable target device.
2. Flashing or preparing bootable media will erase data on the selected device.
3. You will verify the selected device before starting any destructive action.
4. Internal and system drives are blocked by design whenever possible, but no
   safeguard is a substitute for careful review of the selected target.
5. Administrator privileges are required for real write operations.
6. Verification after media creation is strongly recommended.
7. FlashTitan should be used only for lawful installation, recovery, testing,
   and device-preparation workflows.
8. You should stop and review all warnings if device identity, size, health,
   serial information, or write readiness appears unexpected.

If you do not agree to these safety terms, do not continue with installation.
