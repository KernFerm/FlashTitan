# FlashTitan 0.0.27 Release Notes

This file is kept as a historical snapshot for the `0.0.27` release line.

## Version

`0.0.27`

## Highlights

- fixed renderer-side CodeQL findings around HTML attribute sanitization
- improved preset loading safety by switching preset option rendering to DOM-based assignment
- removed attribute-style device button ID wiring in favor of safer runtime binding
- kept the packaged app bridge, USB detection, and preset-loading fixes from the earlier stabilization work

## User-facing improvements

- preset loading remained part of the normal visible image flow
- startup messaging became clearer when the desktop bridge could not start correctly
- device selection rendering became safer without changing how the UI behaved for normal users

## Security and hardening improvements

- removed remaining interpolated attribute writes that CodeQL flagged in `renderer.js`
- preset `<option>` creation moved to DOM property assignment instead of HTML string interpolation
- device selection buttons no longer relied on interpolated `data-*` attributes in generated HTML
- preload bridge continued to use a narrow allowlist and sanitized payload flow

## Stability updates

- preserved the desktop bridge fixes that restored:
  - preset loading
  - removable USB detection
  - packaged app startup behavior
- kept safer fallback behavior when Windows metadata lookups were slow or unavailable

## Packaging notes

- current packaged Windows output was built from the hardened renderer and preload path
- installer and `win-unpacked` builds remained the recommended ways to validate this release
